Extensions

Le moteur Chromium d\'Electron exécute de vraies extensions Chrome, mais Electron ne garantit pas la compatibilité totale : les extensions qui utilisent des API non prises en charge (action, declarativeNetRequest…) seront signalées comme incompatibles.
